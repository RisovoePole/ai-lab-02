# Лабораторная работа №2. Мини-макс с альфа-бета отсечением

Вариант 25: глубина 6, ширина 2, значения листьев [−20; 20].
Эксперимент: одно и то же дерево с разными seed — насколько устойчив выигрыш от отсечения.

## Запуск

```
javac *.java
java Main
```

Файлы:
- `Node.java` — узел дерева и генерация случайного дерева по seed
- `Search.java` — мини-макс и альфа-бета (оба рекурсивные), счётчики узлов и отсечений
- `Main.java` — эксперимент по seed 1..20, замеры времени, таблица, путь, график

## Как устроен эксперимент

- Дерево полное бинарное, 6 уровней ходов: 64 листа, 127 узлов вместе с корнем. Корень — MAX, уровни чередуются.
- Листья — случайные целые из [−20; 20], генератор `java.util.Random(seed)`. Для каждого seed строится одно дерево, на нём запускаются оба алгоритма.
- «Узлов» — число вызовов функции поиска (включая листья и корень).
- «Отсечений» — сколько раз цикл по потомкам прерывался при `alpha >= beta`, когда ещё оставались непросмотренные потомки.
- Время — среднее: 20 замеров по 20 000 запусков на каждый алгоритм и каждое дерево, перед этим прогрев JIT.
- Проверка корректности: если значения корня у двух алгоритмов не совпали, программа падает с ошибкой. Ни на одном из 20 деревьев этого не произошло.

## Оптимальный путь

Для seed = 1: `R L R R L L`, лист со значением 11 (L — первый потомок, R — второй). Значение листа совпало со значением корня (11).
Путь восстанавливается по значениям узлов, которые считает мини-макс: на каждом уровне берётся первый потомок со значением, равным значению родителя.

## Выводы

Мини-макс и альфа-бета вернули одинаковое значение корня на всех 20 деревьях, значит реализация корректна. Альфа-бета всегда посещала меньше узлов, чем мини-макс (127): в среднем 67%, то есть экономия около 33%. При этом выигрыш зависит от seed: от 18.1% до 51.2%, стандартное отклонение числа узлов 11.14 (около 13% от среднего). Размер и глубина дерева одинаковы, меняется только порядок значений в листьях, значит эффективность отсечения определяется именно им. Число отсечений выигрыш само по себе не задаёт (у seed 7 и 14 по 8 отсечений, но 99 и 75 узлов), потому что важно и то, на каком уровне произошло отсечение: чем выше, тем больше поддерево пропущено.
